TEAM INSPIRE | PUREFLOW WEBSITE

Kullanım:
1. ZIP dosyasını çıkar.
2. Klasörün içindeki index.html dosyasını Chrome veya Samsung Internet ile aç.
3. styles.css ve script.js aynı klasörde kalmalı.
4. assets klasörü silinmemeli.

Dosyalar:
- index.html
- styles.css
- script.js
- assets/team-inspire-logo.svg

Not:
Kendi logonu kullanmak istersen logonu assets klasörüne koyup index.html içindeki görsel yolunu değiştir:
./assets/team-inspire-logo.svg
